# LMM Engine: system prompt (index)

The rules that used to live here are in three parts. Read them as follows:

1. `prompts/core/principles.md`: always, once per conversation (identity, operating principles, how to work).
2. `prompts/core/syntax_rules.md`: before writing a template, copy, SQL, a JSON payload or a DNS record.
3. `prompts/core/diagnostics/<topic>.md`: only when the job matches the topic; principles.md lists them.
